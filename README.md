# Claude 封号模拟器

仿 Windows 桌面的虚构互动叙事游戏，使用 Three.js 动态壁纸。与 Anthropic 无关联，停用判定仅为游戏机制，不代表真实规则。

GitHub Pages 静态版：离线预设回复，或在设置 → AI 服务中填写个人 API Key。密钥仅保留在当前页面内存，不写入存档。共享 AI 通过独立服务端代理调用，密钥不在此仓库中。个人服务可自定义 HTTPS 接口地址、模型 ID、输出长度、温度与流式模式；兼容 OpenAI Chat Completions。

资源随仓库提供，无需境外 CDN。GitHub Pages 的实际访问速度受网络影响。


## 随机喜剧桥段

每次发消息有 28% 概率安排一场 8–26 秒后发生的本地剧情；使用过聊天后，空闲满 45 秒也可能出现突发桥段。含“你是中国人吧？”等七组荒诞台词，弹窗停顿后突然停用。与真实身份和所在地无关，不依赖 AI 接口。重置取消未触发事件，复盘明确标注虚构。
