# Claude 封号模拟器

仿 Windows 桌面的虚构互动叙事游戏，使用 Three.js 动态壁纸。与 Anthropic 无关联，停用判定仅为游戏机制，不代表真实规则。

GitHub Pages 静态版：离线预设回复，或在设置 → AI 服务中填写个人 API Key。密钥仅保留在当前页面内存，不写入存档。游戏没有默认 AI 或共享接口，不会自动连接任何模型服务。个人服务可自定义 HTTPS 接口地址、模型 ID、输出长度、温度与流式模式；兼容 OpenAI Chat Completions。

资源随仓库提供，无需境外 CDN。GitHub Pages 的实际访问速度受网络影响。


## 随机喜剧桥段

随机导演含 16 组对话，会结合本局聊天和操作调整抽取权重，最近 3 个事件不重复。新局先留出操作时间，事件之间有随机冷却；既可能虚惊一场，也可能突然停用。两种回应略微影响结局，但不承诺成功。剧情只读游戏内状态，不读取真实身份或设备信息。

桌面交互：文件夹搜索与文档预览、本地邮件草稿及发件箱、网络快速设置、保留文档后切换账号。随机事件会根据当前打开的应用调整权重，不需要真实 AI。
